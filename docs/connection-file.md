# SVNC 连接文件格式 v1

扩展名：`.svnc`（导入时不区分大小写）
编码：UTF-8 JSON，无 BOM
应用声明的 MIME 类型：`application/x-svnc`（项目自定义，未注册）
用途：分享连接设置，并通过 SuperVNC Viewer 导入。

这是与 [SVNC 接入协议](protocol.md) 配套的文件格式。文件格式版本独立于线上接入协议和客户端软件版本。它不改变 SSH 或 RFB 握手。

## 示例

```json
{
  "format": "svnc",
  "version": 1,
  "connections": [
    {
      "name": "设计工作站",
      "profile": {
        "transport": "subsystem",
        "host": "desktop.example.com",
        "port": 5922,
        "user": "vncuser"
      }
    }
  ]
}
```

可直接使用仓库中的 [example.svnc](../configs/example.svnc) 作为模板。示例地址需要改成实际服务器地址。

## 字段

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| `format` | string | 必须为 `svnc` |
| `version` | integer | 必须为 `1`；未知版本拒绝导入 |
| `connections` | array | 包含 1–1000 个连接 |
| `connections[].name` | string | 去除首尾空白后为 1–100 个字符，无控制字符 |
| `connections[].profile` | object | 连接设置，见下表 |

| profile 字段 | 类型 | 含义 |
| --- | --- | --- |
| `transport` | string | 必填：`subsystem` 为 SVNC，`vnc` 为 VNC 直连，`forward` 为通过 SSH 隧道访问 VNC |
| `host` | string | 必填：SVNC 服务器、VNC 服务器或 SSH 隧道服务器地址，依 `transport` 而定 |
| `port` | integer | 对应入口端口，1–65535；省略或为 0 时，分别默认 5922、5900、22 |
| `user` | string | 可选 SSH 用户名；省略时连接时填写；VNC 直连不使用 |
| `jump` | string | 可选 SSH 跳板机名称或本机 SSH 别名；不能以 `-` 开头或包含空白/控制字符；VNC 直连不使用 |
| `vncHost` | string | 仅用于 `forward`，表示从 SSH 服务端访问的 VNC 目标地址；省略时客户端使用 `127.0.0.1` |
| `vncPort` | integer | 仅用于 `forward`，必填，范围 1–65535 |

主机字段使用主机名或 IP 地址，不填写 URL、用户名或端口；拒绝路径分隔符、空白、控制字符及以 `-` 开头的地址。跳板机别名是否存在由导入设备的本机 SSH 配置决定。

文件必须是普通文件，最大为 1 MiB。v1 导入器拒绝未知字段及不符合所选连接方式的字段组合。新增字段需要更新规范及兼容规则，不能假设旧客户端会忽略它们。

## 导入行为

1. 安装带有 `.svnc` 文件关联的客户端后，双击文件可启动或激活客户端并导入。客户端运行中、管理窗口尚未就绪或管理窗口已关闭时打开的文件，仍进入导入队列。导入成功后显示连接列表，不自动连接服务器。
2. 也可从连接管理页工具栏的“导入 .svnc 连接”按钮选择一个或多个文件。
3. 每份文件先完整解析与校验，再原子写入本机连接库；同一文件中的任一连接无效时，这一文件不产生部分导入。多文件分别处理，一份失败不阻止其他有效文件。
4. 新连接生成本机 ID 和创建时间，归入“未分类”，不继承收藏和最近打开状态。
5. 名称和可分享的连接配置完全相同时跳过；同名但设置不同则新增。导入不覆盖已有连接、分类或凭据。去重比较不包含本机私钥路径、钥匙串引用及信任状态；除默认端口外，不做主机别名等价归并。
6. 重复打开同一个文件按相同规则处理，不绑定源文件，不持续同步源文件的后续修改。失败时在管理页显示原因，原连接库保留。

macOS 通过应用包声明文件关联；Windows、Linux 的关联依各自安装包的注册流程生效。在尚未完成系统注册的开发环境，可使用客户端内的导入按钮。系统已有其他默认打开程序时，可在“打开方式”中选择 SuperVNC。

## 导出与凭据

连接卡片的“更多操作 → 导出 .svnc”导出一个连接；v1 文件可由其他工具生成并包含多个连接。导出只保留上述可分享字段。

文件不包含密码、私钥内容或本机私钥路径、钥匙串引用、已保存密码标记、known_hosts 路径、主机密钥信任确认、内部连接 ID 或分类 ID。导入后仍使用本机身份和正常主机密钥校验，缺少账号或密码时由连接流程补填；密码可按现有客户端功能保存在本机钥匙串。

服务端授权仍由 SSH/SVNC 服务端控制，导入文件本身不授予桌面或文件访问权限。
