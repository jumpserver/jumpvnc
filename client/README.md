# JumpVNC Viewer 桌面客户端

JumpVNC Viewer 是 JumpVNC 的桌面客户端，实现 [SVNC 接入协议](../docs/protocol.md)，同时支持普通 VNC。JumpVNC 是产品名，SVNC 是协议名，连接表单中的 SVNC / VNC 表示不同接入方式。构建产物为 `JumpVNC.app`，已有配置目录、应用标识、钥匙串标识和 `.svnc` 连接文件继续沿用，改名后仍可读取原有连接与凭据。

macOS 客户端使用 MyGo 窗口和 noVNC 画布。启动后先进入连接管理页；每个连接在独立桌面窗口中打开。Go 连接 SSH Agent，随后在同一连接中打开 `vnc` subsystem，并尝试打开 SFTP 会话；SFTP 被禁用或不可用时仍可使用桌面。应用仅给内置的 VNC 画布建立临时回环 WebSocket。文件管理默认隐藏，点击标题栏的“文件管理”后展开远程文件；服务端默认以运行账户 HOME 为根目录。

## 构建

需要 Go 1.27.3 或更新版本、Node.js 和 npm。客户端使用独立的 Go 模块。

```bash
cd client
npm --prefix frontend ci
go tool mygo build -skip-dmg
```

应用图标源文件为 `resources/icon.png`，由 MyGo 构建为 macOS `.icns` 并写入应用包，供 Finder 和 Dock 显示。

在 Apple Silicon Mac 上，打开 `client/build/darwin-arm64/JumpVNC.app`。也可用 `go tool mygo build -platform darwin/universal -skip-dmg` 构建通用版本。

## 连接管理

管理窗口默认大小为 1180 × 780，提供原生磨砂半透明侧栏和服务器卡片。侧栏左上角可折叠 / 展开，折叠状态会保留；搜索快捷键也会展开侧栏。左侧可在所有连接、收藏、自定义分类和未分类之间切换，也可按名称、地址、SSH 用户或跳板机搜索。右上角的 `+` 用于添加连接，其余图标支持刷新配置、按名称 / 最近打开 / 最近添加排序，以及卡片和列表视图切换。搜索快捷键为 macOS 的 `⌘K`，其他平台为 `Ctrl+K`。

- 底部工作空间区域支持悬停高亮，点击可查看连接 / 分类数量并刷新连接或新建分类。
- 点击分类区域的 `+` 新建分类，进入分类后可重命名或删除。删除分类会将其中连接移到“未分类”。
- 添加和编辑连接时，协议选择位于最前面，支持 SVNC 和 VNC。SVNC 默认端口 5922，填写服务器地址和用户名，客户端自动使用本机身份及已有密钥配置。账号可以留空，连接时会弹窗补填。VNC 默认端口 5900，可直接连接；勾选「使用 SSH 隧道」后才显示 SSH 服务器、端口、用户名、跳板机和私钥。添加、编辑时可输入 VNC 密码并勾选保存；SSH 隧道也支持输入和保存 SSH 密码。已保存的密码不会回显，留空保留原密码，取消勾选会删除对应的保存密码。旧版 SSH 转发连接自动按 VNC + SSH 隧道展示。表单不使用折叠区。卡片的 `…` 菜单可编辑、移动分类或删除连接，星标按钮用于收藏。
- 点击卡片或“连接”在新窗口打开现有桌面。每个窗口拥有独立的 SSH、VNC、SFTP 和性能状态，可同时连接多个服务器或打开同一服务器的多个窗口。关闭一个桌面窗口只释放该窗口的连接；关闭管理页不会中断已打开的桌面。
- 连接与分类保存在 MyGo 用户数据目录的 `connections.json`，macOS 使用 `~/Library/Application Support/SSH VNC/connections.json`（沿用旧版数据目录）。配置写入采用原子替换，文件权限为 `0600`；损坏或未知版本的配置会显示错误并保留原文件。
- 密码保存到 macOS 登录钥匙串，连接配置只记录引用和保存状态。打开连接窗口后直接连接，背景只显示连接状态；缺少账号或密码时才弹出补填表单。补填弹窗提供「保存」和「连接」两个独立按钮：保存会更新该连接并写入钥匙串，显示成功后可继续连接或取消；仅连接时，补填内容只用于本次会话。已有 g15 连接继续兼容其本机凭据。新安装不自动创建测试连接。排序、视图和画质偏好单独保存在客户端本地存储中。

## .svnc 连接文件

连接配置文件统一使用 `.svnc` 扩展名，格式为 UTF-8 JSON，见 [文件格式规范](../docs/connection-file.md) 和 [示例文件](../configs/example.svnc)。双击文件可启动或激活客户端并导入连接列表，导入后由用户点击连接。也可点击管理页工具栏的“导入 .svnc 连接”按钮；单个连接通过卡片的“更多操作 → 导出 .svnc”分享。

重复配置会跳过，同名但设置不同会新增，导入的连接归入“未分类”。文件不包含密码、私钥、本机路径、钥匙串引用或主机信任状态，导入不会覆盖已有连接的凭据。macOS 需使用重新构建的应用包以包含文件关联；系统默认打开程序未更新时，可通过“打开方式”选择 JumpVNC。

## 连接和传输

- 使用实际服务器 IP 或主机名连接端口 5922，通过 `vnc` subsystem 自动选择后端。服务端 SSH 入口需监听可达地址，例如 `0.0.0.0:5922`；后端 VNC 仍只监听回环地址。旧版保存的转发连接继续使用原有设置，端口不会自动迁移。
- 连接窗口平时不显示连接表单；只有需要补填时才弹出表单。未连接时可通过「连接设置」修改地址、协议等参数，表单内的「保存」只保存配置，不发起连接；取消会放弃本次修改。添加、编辑连接时仍按所选协议显示参数，VNC 密码不放入折叠区，不写入连接配置。SVNC 通过同一 SSH 会话使用桌面及 SFTP；普通 VNC 直连不提供 SFTP。SVNC 可在“SSH 私钥文件”中指定本机私钥路径；Windows 安装程序生成的连接私钥可从服务端管理窗口复制并保存到本机后使用。未指定私钥时自动使用本机身份；加密私钥需先加入 SSH agent。首次连接未知服务器时，核对并确认界面显示的指纹，再保存到本机 `~/.ssh/known_hosts`。已有主机身份不一致时拒绝连接，不自动覆盖。不同跳板机上的回环地址自动使用独立的身份记录。旧 SVNC 连接中保存的私钥、known_hosts 和别名继续沿用，无需在界面重新填写。
- 右侧栏的「上传位置」显示服务器上的实际目录；Linux 默认如 `/home/svnc`，Windows 默认如 `C:\Users\Administrator`。进入子目录后，上传位置和拖放确认同步显示该目录。自定义目录按实际配置显示；旧 Agent 未提供路径时标注为服务端指定。
- 打开侧栏目录后，从 Finder 拖入普通文件，或点击「上传」。拖放后可核对文件名和目标目录，再开始上传。同名文件保留原样，上传失败时面板显示原因。
- 选中文件后点击「下载」或双击文件，使用系统保存对话框选择位置。侧栏也支持刷新目录和新建文件夹。

前端包含 noVNC 1.7.0，构建会随应用附带其许可说明。

`native-rfb.js` 适配固定版本的 noVNC：LibVNCServer 0.9.15 仅声明 Provide 等剪贴板动作时，发送已协商的 UTF-8 Provide，避免中文退回 Latin-1；原生 WebView 在 mousedown 错报 `buttons=0` 时补全按下状态；根据键盘事件中的修饰键状态补全缺失的按下/释放事件。Mac 的 Command 映射为远端 Control，Option 映射为远端 Alt，粘贴前先读取并同步系统剪贴板。只读/未连接策略沿用 noVNC。

远端光标图像和点击热点随桌面显示比例一起缩放，窗口大小变化或展开侧栏时同步更新，避免模拟器等应用的自定义光标在缩小后的桌面上显得过大。Windows 后端在协商 VMware Alpha Cursor 扩展后发送完整 RGBA，保留模拟器原有样式、半透明边缘和阴影；旧服务端继续使用兼容光标格式。缩放时按预乘 Alpha 过滤颜色，避免黑边，Retina 使用高分辨率图像和 CSS `image-set`，显示尺寸与点击热点保持 CSS 坐标。原始光标保留用于重新缩放和详细指标。

## 画质与性能

客户端采用单层浅灰标题栏和桌面内容区，保留原生窗口按钮。左侧标签显示连接名，旁边紧凑显示延迟信号格、桌面接收速率、分辨率和画质档位（悬停信号格查看 SSH 往返延迟数值）；右侧提供剪贴板、文件管理和设置。文件管理与设置按需从右侧展开，关闭后恢复完整桌面视图；Escape 可关闭当前侧面板。

在“设置”中切换画质，连接前后均可操作，无需重连。画质偏好单独保存，默认使用视频模式。旧版保存的流畅、均衡档位自动改用视频，清晰偏好继续保留。

| 档位 | JPEG 画质（0–9） | 压缩等级（0–9） |
| --- | --- | --- |
| 视频 | 3（回退时） | 1（回退时） |
| 清晰 | 8 | 2 |

这些数值通过 RFB SetEncodings 提交给服务端，是客户端请求值；具体效果取决于服务端及实际编码。高压缩等级会增加服务端 CPU 成本。窗口内缩放仍只发生在客户端，不改变远端分辨率或传输像素数。

“视频”在 WebCodecs H.264 解码检测通过时，优先请求编码 50；清晰模式不请求 H.264。Windows 新版后端提供目标 6 Mbps、最高 30 FPS 的 H.264 视频流，优先使用系统注册的 Media Foundation 硬件编码器，初始化或运行失败时自动回退 Windows 内置软件编码器。g15 的 NVIDIA NVENC 已实机验证，其他硬件驱动尚未验收。当前没有自动带宽调节。6 Mbps 是平均码率目标，驱动实际输出、首帧、关键帧和短时速率可以超过目标。旧服务端、不支持的分辨率或无法初始化编码器时按协商使用 Tight 等编码；当前窗口不支持 H.264 解码时显示说明并使用兼容编码。实际图像编码见详细指标，硬编选择和运行状态见后端 `h264.ready` / `h264.stats` 日志的编码器名称与 `hardware` 字段。

视频模式使用全桌面的帧间压缩，适合游戏窗口、动画和连续滚动；NV12 / 4:2:0 会影响小号彩色文字和细线，办公时可切回清晰。切换视频模式会请求一次完整画面刷新，替换静态区域中的旧视频像素。`h264-access-units.js` 修正固定版本 noVNC 将多 slice 画面拆成多个解码帧的问题；升级 noVNC 时需要复验多 slice、模式切换与真实 WebView 显示。

标题栏持续显示简要信息；在“设置 → 详细指标”中查看完整采样，面板关闭时也继续采样：

- **画面更新**：每秒完成且包含图像数据的 RFB 更新数，不代表抓屏 FPS 或显示器刷新率。元数据更新不计入，静止画面可以为 0。
- **桌面接收 / 累计接收**：只统计 VNC 通道的协议数据，不包含 SFTP、SSH 包头或加密开销。速率使用两次采样的实际时间差，首个样本显示采样中。
- **SSH RTT**：每 5 秒发送一次 SSH keepalive 请求得到的往返耗时，超过 15 秒的旧结果不显示。这不是键鼠输入到画面呈现的端到端延迟。
- **实际画面编码**：最近采样区间完成的数据块编码及数量，可以混用多个编码；空闲时显示最近的编码。
- **解码处理 / 块**：调用 noVNC 图像解码处理的平均同步耗时，分段到达的数据块合并计时；不包含浏览器异步 JPEG/PNG 或视频解码耗时。
- **绘制调用 / 次**：Canvas 画面复制调用的平均同步耗时，不代表 GPU 完成或屏幕已经呈现。
- **绘制队列等待 / 绘制队列**：等待 noVNC 绘制队列清空的平均时间，以及当前、峰值待处理操作数量。队列项不等同于视频帧。
- **未解析数据**：noVNC 接收缓冲区中未解析的字节，可能包含尚未完整到达的数据块，不能直接换算成延迟。

约每秒采样一次。断开、重连会清空上一连接的指标；连接中的画质切换保留累计流量。当前不测量服务端抓屏和编码耗时。性能适配依赖固定的 noVNC 1.7.0 内部方法，升级依赖时需运行前端测试并复验真实连接。

已搁置的虚拟屏原型文件不会编入当前应用。

```bash
npm --prefix frontend test
go test -race ./...
go vet ./...
```

## LibVNCServer 后端与文本剪贴板

正式 MyGo 客户端使用 noVNC 1.7.0 解码；LibVNCServer 用于 Windows 服务端。`client-libvnc` 是独立的 LibVNCClient/SDL 实验客户端，尚未替换正式客户端。标题栏连接名的提示和“设置 → 当前连接”显示 SVNC 入口（旧转发模式下同时显示后端 VNC 端口）与服务端上报的桌面名称，“详细指标”明确显示客户端解码实现。

当前连接窗口激活时，文本剪贴板默认自动双向同步，无需打开“剪贴板”窗口。本机复制后切回远程桌面即可粘贴；远端复制后可切回本机应用直接粘贴。后台连接不读取或改写系统剪贴板。客户端通过 MyGo 原生剪贴板 API 读取纯文本，每 250 ms 检查一次变化；相同文本与 CRLF/LF 换行差异不会重复发送，断开后停止同步。文件和图像不会作为空文本同步。

Mac 使用 ⌘C / ⌘V，Windows / Linux 使用 Ctrl+C / Ctrl+V；Konsole 等终端使用 Ctrl+Shift+C / V，Mac 对应 ⌘Shift+C / V。剪贴板窗口保留手动发送和复制到本机按钮，并显示同步状态或错误。发送只更新剪贴板，仍需在目标应用中执行粘贴。UTF-8 取决于服务端 ExtendedClipboard 支持；客户端文本上限为 1 MiB，原生 Linux 后端仍受其 64 KiB 上限约束。文件传输继续使用 SFTP。

2026-11-20，重建 macOS 客户端后，在 `alivnc · KDE Plasma 6` 实测通过：手动发送中文、多行、emoji；本机复制自动同步到 X11 `CLIPBOARD`；远端复制自动写入 Mac 系统剪贴板且可用 ⌘V 直接粘贴；⌘Shift+V 在 Konsole 粘贴中文。测试输入已清除，剪贴板恢复为测试前文本。Windows 后端本次未重新验收。

未获得 SFTP 会话时文件按钮禁用，桌面和剪贴板仍可使用。已有文件传输权限仍由 Agent 执行；客户端按钮状态不代表服务端完整的上传/下载授权。
